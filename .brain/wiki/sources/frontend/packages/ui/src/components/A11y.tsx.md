# frontend/packages/ui/src/components/A11y.tsx

**Role.** The two screen-reader plumbing primitives: `VisuallyHidden`, a bare `sr-only` span for text that must reach the accessibility tree but never the screen, and `SkipLink`, the first focusable element on every page — invisible until focused, then jumping focus to the page's `<main tabindex="-1">`.

**Module.** [[frontend/packages/ui/src/components/_index]] · **Layer.** ui

## Public Surface

| Symbol | Kind | Purpose |
|---|---|---|
| `VisuallyHidden` | component | `{children}` → `<span className="sr-only">`. Nothing else; no ref, no props passthrough. |
| `SkipLink` | component | `{href, children}` → an `<a>` styled `sr-only` at rest, `focus:not-sr-only` and absolutely positioned on focus. |
| `SkipLinkProps` | interface | `href` is documented as the **fragment target** of the page's `<main tabindex="-1">` — the `tabIndex={-1}` on the target is what makes the jump actually move focus rather than only the scroll position. |

## Behavior

`SkipLink`'s class list is the whole story, and the padding placement is a deliberate fix rather than styling taste. `sr-only` sets `padding: 0` to collapse the element to a 1×1 clip; a plain `px-4 py-2` in the base class overrides that and leaves a ~64px-wide **invisible but laid-out** box that still contributes to `scrollWidth` — which trips the horizontal-overflow assertions once page gutters grow. So every padding, position, z-index and shadow utility here is prefixed `focus:`, applying only once the link is revealed. Positioning uses the logical `inset-s-2` (start), not `left`/`right`, so the revealed link lands on the correct edge under `dir="rtl"`; [[frontend/scripts/qa-greps.sh]] mechanically bans the physical variants. `focusRing` from [[frontend/packages/ui/src/lib/styles.ts]] is appended last, but note that `cn()` is a plain join with no class-merge — nothing here relies on a later class beating an earlier one at the same specificity.

Neither component reads i18n; the link text arrives as `children`, which is the package-wide rule (`packages/ui` has no i18next dependency and must not gain one).

## Notes
